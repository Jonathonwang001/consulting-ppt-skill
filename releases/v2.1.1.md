# v2.1.1 — 整体适用性与交付统筹 / Holistic applicability and delivery

## 中文

本版聚焦consulting-ppt本体，不扩展字典工程。沿用v2.1的有效深度、组合视觉证据和排版硬门槛，避免只按单次反馈加局部规则。

1. 先识别受众、实际用途、证据成熟度、阅读媒介与交付约束，再规划整稿/章节/页面。内外、投屏/阅读、决策/信息是不同维度。
2. 新增规划场景`external_report`：对外成果、专题研究、专业交流不强套Proposal的报价/资历/客户研究投入。非Proposal工作计划仍需事项/状态/Owner/节点；纯信息或诊断不强造计划。
3. 整稿故事线、章节信息预算、术语、数据/单位/期间、分类和色义先统一；标题连读体现推进。相关多观点/子关系可共同支持一个阅读任务，不固定一页一图一观点。
4. 合理重排标题/摘要、表格/栏宽/模块以减少无意义留白，同时保留分组、呼吸和用户指定设计元素；不能删风险、缩字或堆满画布。
5. 报告优先可编辑Markdown，演示优先原生可编辑PPTX及可改图表数据；地图按需配Mermaid，实际计算/评分图表按需配CSV与所用Python。清晰成品是主入口，源文件是支撑。
6. 报告/打印版按A4检查表格、跨页、字体、来源；投屏按其画布/视距检查。实际交付媒介、可编辑能力与最终渲染均须验收。

保持2.0/2.1规划schema；2.1仅增加external_report枚举，旧输入不变。保留原Proposal、咨询框架、图标语义、配色与真实格式底线。布局检查器仍只消费声明指标，规划/合成测试不能认证真实PPT或替代专业事实研究。

## English

This release improves the skill itself, not a separate dictionary project. Coordinate audience, purpose, evidence maturity, medium and delivery constraints before planning the whole artifact, chapters and pages. External/internal, presented/read and deciding/informing are independent dimensions.

Add `external_report` for non-proposal results/research/exchanges without sales closure. Non-proposal work plans still need issue/status/owner/checkpoint tracking; informational or diagnostic pages need not invent action plans. Preserve schemas 2.0/2.1 with an additive 2.1 scene enum.

Check whole-document narrative, chapter information budgets and consistent terms, figures, units, periods, classifications and color semantics. Reduce purposeless whitespace by thoughtful reflow without hiding risks or overcrowding. Prefer editable Markdown/PPTX and optional Mermaid/CSV/actually used Python sources behind a human-facing main artifact. Validate A4 reports/print separately from projection and verify actual editability/rendering.

Preserve consulting methods, proposal closure, icon semantics and strict text/font/layout gates. Planning and synthetic bounds tests do not certify real decks or replace specialist evidence analysis.
