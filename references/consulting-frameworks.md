# 咨询框架速查手册

## 战略分析框架

### 3C分析（Company / Customer / Competitor）
**用途**：全面评估竞争环境，识别差异化机会
**页面结构**：三列布局，每列一个C，用图标区分
```
公司（Company）    客户（Customer）    竞争对手（Competitor）
• 核心能力         • 需求痛点           • 主要玩家
• 资源禀赋         • 消费行为           • 竞争策略
• 战略意图         • 支付意愿           • 优劣势
```
**结论导向**：三个C分析完后，必须有一个"战略机会空间"结论框。

### 波特五力模型（Porter's Five Forces）
**用途**：评估行业吸引力和竞争强度
**页面结构**：中心圆（行业竞争）+ 四角四力
```
              供应商议价能力
                    ↓
潜在进入者 → [行业内竞争] ← 替代品威胁
                    ↑
              买方议价能力
```
**评分方式**：每个力量标注高/中/低，并说明主要驱动因素。

### BCG矩阵（Boston Consulting Group Matrix）
**用途**：业务组合管理，资源分配决策
**四象限**：
- **明星（Stars）**：高增长+高份额 → 持续投入
- **现金牛（Cash Cows）**：低增长+高份额 → 收割利润
- **问题儿童（Question Marks）**：高增长+低份额 → 选择性投入
- **瘦狗（Dogs）**：低增长+低份额 → 考虑退出

### 安索夫矩阵（Ansoff Matrix）
**用途**：增长路径选择
```
          现有产品        新产品
现有市场  市场渗透        产品开发
新市场    市场开发        多元化
```
**风险递增**：市场渗透（最低）→ 多元化（最高）

### 麦肯锡7S框架
**用途**：组织变革诊断，确保变革各要素协调
**七个要素**（分硬性/软性）：
- 硬性：战略（Strategy）、结构（Structure）、系统（Systems）
- 软性：共同价值观（Shared Values）、风格（Style）、员工（Staff）、技能（Skills）
**页面结构**：蜘蛛网图或七边形，中心放"共同价值观"

## 运营分析框架

### 价值链分析（Value Chain Analysis）
**用途**：识别价值创造环节和成本优化机会
**结构**：
```
主要活动：进货物流 → 生产运营 → 出货物流 → 市场销售 → 售后服务
                          ↑
辅助活动：基础设施 / 人力资源 / 技术开发 / 采购管理
```
**分析重点**：在每个环节标注成本占比、增值贡献、改善机会。

### SWOT分析
**用途**：内外部环境综合评估
**四象限**：
- **S（Strengths）优势**：内部正面因素
- **W（Weaknesses）劣势**：内部负面因素
- **O（Opportunities）机会**：外部正面因素
- **T（Threats）威胁**：外部负面因素

**进阶用法（TOWS矩阵）**：
- SO战略：用优势抓住机会
- ST战略：用优势规避威胁
- WO战略：利用机会克服劣势
- WT战略：减少劣势避开威胁

## 财务分析框架

### 杜邦分析（DuPont Analysis）
**用途**：拆解ROE驱动因素
```
ROE = 净利率 × 资产周转率 × 财务杠杆
    = (净利润/营收) × (营收/总资产) × (总资产/股东权益)
```
**页面结构**：树状分解图，从ROE逐层向下拆解。

### 瀑布图（Waterfall Chart）
**用途**：展示财务指标的变动来源分解
**典型场景**：
- 收入变动分解（量/价/结构）
- 利润桥接分析（上期→本期）
- 成本变动分析

**颜色规范**：
- 起始/终止总计：深蓝色实心柱
- 正向贡献：绿色 `#059669`
- 负向贡献：红色 `#dc2626`
- 中性/基准：灰色 `#6B7280`

## 项目管理框架

### RACI矩阵
**用途**：明确项目各角色的职责
- **R（Responsible）**：执行者
- **A（Accountable）**：负责人（最终决策）
- **C（Consulted）**：被咨询者
- **I（Informed）**：被通知者

**页面结构**：行=任务，列=角色，格子内填R/A/C/I。

### 变革管理曲线（Kübler-Ross Change Curve）
**用途**：管理组织变革中的人员情绪和阻力
**阶段**：否认 → 愤怒 → 讨价还价 → 沮丧 → 接受 → 整合
**页面结构**：横轴时间，纵轴绩效/情绪，S形曲线，标注各阶段干预措施。

## 市场分析框架

### TAM/SAM/SOM（市场规模分析）
- **TAM（Total Addressable Market）**：总可寻址市场
- **SAM（Serviceable Addressable Market）**：可服务市场
- **SOM（Serviceable Obtainable Market）**：可获得市场

**页面结构**：三个同心圆（由大到小），标注各层规模和占比。

### 客户旅程地图（Customer Journey Map）
**用途**：识别客户体验痛点和改善机会
**横轴**：客户旅程阶段（认知→考虑→购买→使用→推荐）
**纵轴**：
- 客户行为
- 客户情绪（曲线，高=正面，低=负面）
- 痛点（红色标注）
- 机会点（绿色标注）
