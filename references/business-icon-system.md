## 1. 先定关系，再选图标

图形回答“如何关联”，图标回答“哪个实体或活动”，标签说明项目语境，数字与来源负责证据。先写主要阅读任务和内容证据，需要关系结构时再选择；客户决策仅是Proposal/真实决策场景的任务之一。为需要快速辨识的实体选择图标，不从素材库有什么反推报告内容。

选择流程：读者任务/证据→需要时选择关系/主表达→识别对象→直对应图标→配准确标签→检查风格/可读性/许可。不把灯泡、火箭或齿轮泛指所有战略概念。标签约2–6字可作精简启发，但准确性优先；同组角色用名词、活动用动宾。移去图标后逻辑仍须成立，歧义图标可以不用。

本规则来自三套用户素材的实际视觉审阅（共102页概览、35页代表深读），不是图标包或资产授权。A/B/C来源和页码见`source-learning-map.md`；以下流程组合是技能应用推导，不是素材中已证明的业务事实。

## 2. 语义选择词典（有限、按需）

| 概念 | 可选实体/动作词汇 | 可定位素材证据 | 必须限定与不得推导 |
|---|---|---|---|
| 客户/角色/团队 | 中性人物、会议、通讯录 | B p1/5/6/8；C p32 | 写具体角色；不代表真实肖像、人数、编制或职级 |
| 沟通/协作 | 圆桌、对话、握手、扩音器 | B p5–6；C p32 | 标协作/沟通，握手不证明已签约或控制关系 |
| 终端与系统 | 电脑、手机、路由器、云 | C p15 | 写实际对象；不证明云部署、智能化或具体品牌 |
| 数据与记录 | 数据库、文件、文档 | C p73 | 标数据域与动作；不证明性能/可追溯性已达标 |
| 运营服务 | 耳机、对话、扩音器 | C p32/73 | 标响应/触达；不暗示7×24承诺或满意度 |
| 治理/权限/状态 | 锁、勾/叉、必要的状态符号 | B p4；C p73 | 标依据与状态；不冒充安全认证、评级或完成 |
| 交易/财务 | 购物车、银行卡、货币 | A p2；C p73 | 标渠道/币种/结算；硬币高度不等于收入 |
| 时间与计划 | 日历、时钟 | C p73/81 | 日期另写；指针不等于项目期限，钟表不是甘特 |
| 路径与分支 | 地点、条件分支 | C p80 | 道路转弯不能直接冒充业务因果，关系重新绘制 |
| 创意/待解问题 | 人物问号/灯泡 | C p32 | 指真实问题或创意活动；不代表专利或领先等级 |
| 特定行业符号 | 洗护、手势等 | C p77/82 | 仅在含义/标准核实的行业语境使用，不能随意借喻 |

抽象价值可以直接用文字与结构，不必拟物。来源有这类图标不表示可将其复制进公开作品；实际使用先检查许可。

## 3. 11组内容—关系—图标正反例

以下为假想业务输入，用于检验规则，不是实际客户成果。

| 输入 | 合格：结构先行+图标辅助 | 不合格与原因 | 素材词汇依据 |
|---|---|---|---|
| 采集数据、存储、服务响应 | 若确实有顺序，用流程节点/数据流；终端、数据库、耳机配标签 | 三个齿轮写数字化/智能化/生态化，无明确对象和方向 | C p15/73 |
| 多部门共同评审 | 同级角色共同连“评审”，线标协作，人物配岗位 | 大头像在上暗示领导关系；通用头像冒充实人 | B p5–6；C p32 |
| 权限、留痕、服务三项能力 | 并列框，锁/文档/耳机识别能力，证据与指标另写 | 图标锁配“100%安全”或勾配“完全合规”，无认证依据 | C p73 |
| 触达、沟通、合作对接 | 真有先后才用箭头；扩音器/圆桌/握手配活动标签 | 无转化数据画漏斗，握手直接叫“已签约客户” | C p32 |
| 审批周期与任务日期 | 甘特承担时间与依赖，时钟仅辅助周期标题 | 每行不同钟面要求读者猜日期或工作量 | C p73/81 |
| A/B方案分流 | 先定义决策条件与分支，再用文档/设备识别对象 | 道路/环岛符号直接叫战略转型，无条件或关系定义 | C p80/73 |
| 渠道交易额变化 | 真实数据柱线/瀑布；购物车仅作类别标签，可不用 | 素材上升柱图冒充增长强劲，硬币堆代替数据 | A p2；C p28/73 |
| 企业主体交换数据 | 真实节点/连接/流向，终端/数据库辅助实体 | 分子状网络直接叫独有技术架构，关系未经验证 | C p27/15/73 |
| 培训提问与学员回应 | 培训场景可用相关人物动作，删除无关戏剧元素 | 打瞌睡/踢人小插画被当作真实员工执行力证据 | C p57 |
| 一条结论或尽调证据表 | 不用图标，保留标题、证据、来源与状态 | 每句灯泡、每个表格格子加图标，增加视觉噪音 | C p32/73 |
| 产品洗护要求 | 核实标准符号与文字，按真实洗护语义使用 | 禁水洗借喻风险隔离、熨斗借喻先进制造，语义错误 | C p82 |

## 4. 模块组合与光学一致性

箭头的图标是可选识别层；树/矩阵的层级与轴先行；漏斗/瀑布以真实数据为核心；甘特的时间条与交付物已足够时无需每行加时钟。编号已实现导航时不再叠图标。现状/目标勾叉须有判断标准，不能把方案取舍变成简单“对/错”。

**按家族而非文件选择**。C p15多色设备、p27白线网络、p28手绘、p73细线圆框不是同一家族；仅改成同色不能消除差异。统一实心/线性/扁平、线宽、圆角、细节密度、透视与底板，再统一颜色。优先一套低复杂度家族；主色和中性灰为主，状态色配文字。

**按可见轮廓对齐**。同尺寸文件框不等于同视觉重量；手机细长、握手较宽，人物加问号/盾牌会扩大外框。统一容器内保留宽高比，调整光学尺度，统一视觉中心、标签基线、人物头/肩线及节点锚点；箭头接容器，不穿头像、孔洞或文字。同家族圆框统一保留或移除。

**最终尺寸复核**。复合图标默认一个主要实体加一个必要状态/动作；细节缩小不可辨时换简单图标、状态改文字。复杂人物场景是小插画，适合培训解释，不适合高密度决策页。不要通过放大图标填空。

## 5. 可编辑素材的结构限制

A主要是4,656原生形状、0图片、10组合；B为536形状、0图片、93组合。它们支持原生矢量形状证据，但形状数不是图标数，组合数也不是图标数。A p8有1,549形状且0组合，复制单图标需完整选取细部、轮廓和负形，不可漏选。

C为31,930形状、36图片、458组合，是混合素材。p28含15个EMF及14个PNG嵌入图片，p41/43另有PNG；说明页p2–3宣称可编辑不能代替实际结构核查。EMF含矢量绘制不等于可单部件改色的PPT形状；PNG不承诺矢量填充。改色保留屏幕、孔洞、前后层等辨识细部。

本次没有逐图标PowerPoint交互测试、去重语义索引或全部资产授权确认。源素材概念柱图/曲线不是有数据来源的原生图表，不能用于冒充分析结果。

## 6. 真实性、许可与使用检查

不冒充数据、实人、客户logo/合作背书、认证/评级或完成。图标大小、数量、位置默认无数量含义；若明确做图示计数，标每个符号单位、真实数量与分母/来源，并处理非整数。

用户上传供学习不等于拥有商业/衍生/公开再分发权。素材作者字段、没有license文件、可编辑说明均不是许可依据。**不要公开上传原PPTX、渲染PDF、联系表、截图、抽取媒体或源形状导出SVG**；许可未确认时使用独立、明确许可的资源或原创表达，不靠改色、描摹、矢量化规避权限。

未来调用技能时按文件名查找用户当前提供的授权原件，并核对页码和对象；没有文件就索取/选合规替代，不能声称来源仍可用。公开Skill仅含方法与索引，不含原始图标全集。交付前检查：有识别价值、配准确标签、同家族光学一致、无语义/数据/身份误导、完整选取与最终尺寸可读、素材许可明确。
