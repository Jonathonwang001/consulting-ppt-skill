# 交付质量门槛与验收

## 1. 场景、阅读者与完整内容

- [ ] 五维简报覆盖受众、用途、证据成熟度、媒介和交付约束；内外不替代用途判断，非Proposal不套获客六模块，纯信息不造票决。
- [ ] 用户修改要求和领导认可的模板/结构/图表/案例图片已按可用原件复用，缺失/许可限制如实说明。
- [ ] 执行摘要与各章小结覆盖核心判断、关键证据、风险和关注/行动；用同页总结栏也可，避免重复过渡。
- [ ] 每条内容有论点、证据、比較、反证、口径、风险、影响、选项或行动作用；有效深度保留，无支撑重复淘汰。
- [ ] 正文到支撑页可追踪，数字/计算、访谈、同业对比与关键不利证据不因图美或讨好而删减。
- [ ] 标题真实准确，假设保留限定，导航/方法/计划页可用功能标题。
- [ ] Proposal研究闭环完整；内部进度/行动页有事项/状态/责任/节点，纯诊断页无需客户投入字段。
- [ ] 商务条款、团队CV、价值和案例未虚构；研究对象/样本/资源与排期有依据；示例非真实成果。

## 2. 观点—证据与可视化

- [ ] 主要阅读任务明确，图表/表格/关系图由内容选择；无需每页套一个框架。
- [ ] 组合模块各有证据作用、共享或解释不同口径、阅读顺序与主次清楚；支持同一判断而非无关堆叠。
- [ ] 结构+图表组合不物理遮挡；双轴、不同期间/分母和示意网络不暗示未经证实因果。
- [ ] 矩阵轴/评分、箭头关系、漏斗cohort、气泡面积/数量几何明确且可复核。
- [ ] 图标有识别价值、配标签、同层同家族与光学重量；可无图标，图标不替代数据。
- [ ] 原素材/人物/商标/客户图片的用途许可可核查，不冒充实人、合作或认证，不擅自公开源资产。
- [ ] 真数字有来源/日期/版本；假设/估算/预测/计划/示例状态可区分，单位/期间/分母和比较口径一致。

## 3. 工程硬门槛：任何失败阻断交付

- [ ] 文字内容与稿件逐项一致，没有漏尾字、尾行、项目符号、公式/上标或单元格内容；截断藏在框内同样失败。
- [ ] 字形墨迹在扣除内边距的文字内容框内，四边均无溢出；变换后语义对象在幻灯片画布内。
- [ ] 图表轴/刻度/负号/单位/图例/标签完整，在声明的标签安全区内；允许plot外图例但不越页面。
- [ ] 无文字互压、图标挡数值、引线穿标签、对象裁切或覆盖来源；有意底板/层叠不遮语义。
- [ ] 项目字体/字号层级/行距/段距/网格/页脚一致；目标应用和最终导出无缺字、方框、错误字体替代或换行漂移。
- [ ] 实际目标阅读尺寸/视距可读；不靠无限缩字、自适应裁切、删掉风险或把证据移出画布过检。
- [ ] 全页完成真实渲染与审阅；任何后续改字/换字体/调整框都对受影响页重验。

项目字体样式是契约，15字/60%等配额是启发；两者不能混同。规则详见`typography-layout-contract.md`。

## 4. 检查工具与证据记录

| 检查 | 能证明 | 不能证明 |
|---|---|---|
| Skill quick_validate | 技能结构/frontmatter | 场景适配或真实PPT质量 |
| lint_slide_brief.py | 场景与规划字段、来源/图标/几何声明及必要闭环 | 事实/真正MECE/字符渲染/素材许可 |
| check_layout_metrics.py | 输入bbox的内容框/region/画布包含关系、审阅声明字段 | 指标真实或全覆盖、实际字体、隐蔽截字、全部遮挡 |
| 最终文件全页渲染+内容核对 | 记录环境中的真实可读性/完整/边界问题 | 未审查环境中必然相同表现 |

验收记录写文件版本或哈希、工具/环境、页与对象ID、内容/工程检查项、失败原因与修复/复验。合成bbox样例默认不能通过真实验收，测试标识始终保留；人工作页/对象审阅无机器bbox时可记实，不伪造测量。

至少测试Proposal有/无图标、内部及对外非Proposal无需获客闭环、组合页多模块与布局超框/裁切/漏字/字体声明失败。测试总数依据实际运行，合成与规划测试不代表真实稿认证。

## 5. 修复与发布

先记录失败页/对象→去无效重复→调整版式/换行/模块→同稿补充证据页→项目契约内字号调整→重渲染/复验；有效深度和风险不因此删除。内容/工程各门通过后交付；未决证据与资产许可标清边界。

GitHub发布核对远端文件与完整tree，而非仅看提交SHA：网页原生提交可与本地提交ID不同但tree相同。既有版本tag不覆盖，新版本记录新tag/Release和实际远端commit。

## 6. 整稿与交付统筹

- [ ] 故事线回答实际问题，章节间证据/判断一致，标题连读体现推进，不靠页型凑篇幅。
- [ ] 全文术语、数值、单位/期间/分母、分类和色义统一；风险和不利证据与摘要不冲突。
- [ ] 信息预算按读者/用途分层，不强求所有页同密度；无意义留白通过摘要/标题同页、栏宽/表格/模块重排改善，保留必要呼吸和指定设计元素。
- [ ] 可编辑文字、节点/图形和真实图表数据在交付源文件中可改，不能以整页图片替代；成品导航清晰，Markdown/PPTX与按需Mermaid/CSV/实际所用Python来源对应。
- [ ] 报告/打印版A4列宽、分页、重复表头、字体、来源完整可读；投屏另按实际画布/视距验收，不把一种格式合格当作所有媒介合格。
- [ ] 用户主入口是直观成品，不是原始代码/JSON堆砌；预览PDF/图片与源稿一致，未核验编辑或渲染能力明确说明。
