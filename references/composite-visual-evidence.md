# 组合视觉证据：一个阅读任务、多个协调模块

## 1. 定义与适用范围

当单个图表或关系结构不足以支撑观点，按主要阅读任务组合互补证据模块。保留关系/实体/度量纪律；一页可以有不同子关系，只要对同一判断有明确作用。已批准样例与框架优先，单图表/表格已足够时不用复合方案。

逻辑叠加可采用上下/左右分区、对齐小多图、同编号映射或注释带。物理布局避免文字、轴、图例、关键数据、标签互相遮挡；图内注释仅在同坐标且有业务意义时出现，不能用图覆盖图。支持与反证可以并置，共同说明判断成立的条件。

## 2. 组合选择表

| 主任务 | 可用组合 | 对齐与映射 | 使用前核查 |
|---|---|---|---|
| 理解机制并检验结果 | 作用机制+趋势/同业对标 | 节点ID对指标，线说明假设/测量对应 | 工况、基线、单位、样本与来源；无数据用验证表 |
| 比较方案及依据 | 矩阵+评价明细表 | 方案ID一致、轴定义与评分可回查 | 无可比评分不放精确点位，主观成分标明 |
| 解释投资/业务卡位 | 价值链+重点环节指标/能力放大图 | 高亮环节与放大区同编号 | 规模和关系分开，实物/信息/资金流不混同 |
| 监督项目交付 | 甘特/依赖结构+里程碑/风险表 | 任务/节点ID与表行对应 | 日期/Owner/资源真实，拟排期标待确认 |
| 检验观点与否证 | 支持证据+冲突/风险栏 | 同一假设ID，分支持/冲突/尚缺 | 不用绿色状态把未证伪装通过 |
| 解释变化及后续 | 真实桥接+原因/动作表 | 变动项对解释与措施 | 加总/期间一致，未知项不凑平 |
| 同口径跨对象比较 | 同尺度小多图+口径说明 | 统一轴、期间与对象 | 差异明确，不为省空间随意双轴 |
| 暂无量化证据 | 定性机制/方案+验证/缺口表 | 明示假设/非按比例 | 不造趋势、气泡面积、转化或排名 |

如果矩阵坐标不能复算，优先评价表；若读者直接比量值，优先同尺度面板。条款、长口径、访谈摘录可用文字，不强迫每条内容图化。

## 3. 逐页程序

1. 写主阅读任务和观点成熟度，再确定获批框架位置；不能先决定“做机制+折线”再寻找理由。
2. 列每块模块的作用：支持观点、揭示反证、定义口径、说明风险或承接行动；无增量的模块删掉/移支撑。
3. 定义共用对象ID、指标/期间或映射；无法对齐的差异显著说明，不悄悄改分母。
4. 解释连接：先后、依赖、测量对应、对比或待验证因果。纯视觉对齐不证明关联。
5. 分配标题、证据、边界/动作和来源区，再排内容；空间不足重排或同稿拆页，先保有效信息不先缩字。
6. 复核标题任务清楚、沿模块能看懂论证、查注释可复算口径，反证在主阅读路径可见。
7. 最终渲染按`typography-layout-contract.md`检查四边/尾字、坐标/图例、字体替代与遮挡，失败修复重验。

## 4. 硬门槛与启发式

硬门槛：每模块有任务贡献；事实/评分有真实来源与口径，示意与事实分开；数量几何可复核；相关不冒充因果；不删关键风险/限定为图美让路；零非预期溢出/裁切/遮挡，字体和阅读环境正确。双轴确有业务需要时标单位和目的，不能靠轴缩放造共变。

启发式：主证据有清楚层级、支撑次之，阅读顺序可从观点到证据再到边界，也可在领导熟悉框架时先呈关键偏差。比例、模块数、字数按用途调整，不固定60%；模块多到需要频繁来回寻找时拆页。图标有识别价值才用，数字图表/口径页可无图标。

## 5. 假想输入→设计与补证

假想内部战略研究：领导已批准“场景需求→能力边界→候选卡位→验证计划”框架，要求会前理解和讨论，暂不选择投资标的。输入只有匿名技术说明、内部能力清单、访谈和缺口，没有可比趋势、评分或批准日期；以下不是真实项目事实。

| 页/主任务 | 组合与有效内容 | 当前限制 |
|---|---|---|
| 执行摘要 | 当前判断+依据/风险/讨论项 | 标阶段假设，不作投资选择 |
| 场景需求 | 需求关系图+访谈/工况定义表，同场景ID | 访谈代表样本，未知工况待取 |
| 系统验证 | 定性作用机制+指标/条件/缺口表 | 无数据不画改善趋势，作用线待验证 |
| 需求章小结 | 新认识+支持/冲突/尚缺与下章关联 | 回指证据，不新增已证结论 |
| 能力边界 | 价值链+高亮环节责任/接口放大图 | 内部清单不等同量产能力，争议保留 |
| 能力章小结 | 已有/待证/待补能力+接口争议 | 不删除不利责任边界 |
| 候选卡位 | 路线/适用条件/替代/证据表+取舍问题 | 无评分不摆矩阵点位 |
| 卡位章小结 | 当前判断条件+可能推翻的事实 | 无收益率/排名/最优标的 |
| 验证计划与章小结 | 依赖泳道+验收条件/拟责任+同稿支撑索引 | 无日期不冒充定量甘特 |

取得可比实测时，将系统验证右侧换成趋势/同业图，保留机制与替代解释；两轴和评分确认后可加矩阵，明细表仍可查；日期/资源获批后可升级甘特。新数据若反驳假设，更新标题、摘要与小结，不能只换图不改判断。

## 6. 简报和工具边界

在`slide-content-template.md`与2.1JSON的`evidence_modules`记录每块`id/kind/supports`及真实来源；它检查作用声明，不自动证明相关性或客观性。实际碰撞、字体、漏字和遮挡仍依全页审阅；布局指标脚本只核查实测bbox/声明，不自动创建或理解组合图。
