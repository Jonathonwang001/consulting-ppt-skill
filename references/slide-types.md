# 幻灯片类型详细规范

## 封面页（Cover Page）

**必须包含的元素：**
- 项目/报告标题（大号Serif字体，主色）
- 副标题（描述性，小号）
- 客户名称（显著位置）
- 汇报机构名称
- 日期
- 保密级别（Strictly Confidential / For Client Use Only）
- 版本号（如适用）

**麦肯锡风格**：深海军蓝满版背景，白色文字，左下角金色细线装饰，极简克制。
**罗兰贝格风格**：酒红色顶部色块（占页面1/3），白色文字，下方白色区域放项目信息。
**德勤风格**：黑色或深炭灰背景，白色文字，右侧或底部品牌绿色点缀线条。

---

## 议程页（Agenda）

**结构**：编号圆圈（01/02/03/04）+ 章节标题 + 简短描述

**布局选项**：
- 四象限布局（2×2网格，每格一个章节）
- 垂直列表（左侧编号，右侧标题+描述）
- 水平时间线（适合按时间顺序的议程）

**当前章节高亮**：用主色填充当前章节编号圆圈，其余用灰色轮廓。

---

## 章节过渡页（Section Divider）

**结构**：
- 深色背景（主色满版或渐变）
- 大号章节编号（如 "02"，极大字号，半透明叠加）
- 章节标题（白色，大号Serif）
- 章节副标题（白色，小号，描述本章内容）

**作用**：视觉节奏的重置，给受众心理上的"换挡"感。

---

## 问题树（Issue Tree）

**层级规范**：
- **根节点**：深色背景圆角矩形，白色文字，放置核心问题
- **Level 1**：主色系色块（每个维度一种颜色），左侧有竖线连接
- **Level 2**：Level 1颜色的浅版（透明度40-60%），缩进
- **Level 3**：灰色边框，白色背景，进一步缩进

**MECE标注**：在每个Level旁可加注"MECE"标记，确保分支完整。

**颜色分配示例（麦肯锡风格）**：
- 维度1：`#002F6C`（深蓝）
- 维度2：`#1a5276`（中蓝）
- 维度3：`#2980b9`（亮蓝）
- 维度4：`#85c1e9`（浅蓝）

---

## 工作计划/甘特图（Work Plan / Gantt Chart）

**必须包含的元素**：
- 横轴：周次（Week 1, Week 2...）或月份
- 纵轴：项目阶段 → 具体任务
- 阶段色块：每个阶段一种颜色，横向延伸表示时间跨度
- 里程碑：菱形标记 ◆，标注关键交付物
- 负责人（可选）：任务右侧标注

**阶段颜色规范**：
- 阶段1（诊断/调研）：深蓝 `#1a3a5c`
- 阶段2（分析/设计）：中蓝 `#2563eb`
- 阶段3（实施/落地）：绿色 `#059669`
- 里程碑：橙色/金色 `#d97706`

**关键里程碑标注**：在菱形下方写交付物名称，如"期中报告"、"最终汇报"。

---

## 现状对比（As-Is vs To-Be / Comparison）

**双栏结构**：
```
┌─────────────────┬─────────────────┐
│   现状 As-Is    │   目标 To-Be    │
│  （灰色/红色）  │  （绿色/蓝色）  │
├─────────────────┼─────────────────┤
│ • 问题点1       │ • 改善方向1     │
│ • 问题点2       │ • 改善方向2     │
│ • 问题点3       │ • 改善方向3     │
└─────────────────┴─────────────────┘
         ↓ 转化箭头（中间）
```

**变体**：
- Before/After（改革前后）
- Current State / Future State
- Problem / Solution

---

## 数据图表（Data Chart）

**必须包含的元素**：
- 图表标题（Action Title，说明图表结论）
- 图表本体（柱状/折线/饼图/散点图）
- **关键洞察标注框（Key Message Box）**：用彩色边框框住，1-2句话说明最重要的发现
- 数据来源（Source: xxx, Year）
- 图例（简洁，不超过4种颜色）

**关键洞察标注框样式**：
```
┌─────────────────────────────────────────┐
│ Key Insight: 2023年Q4增速放缓至8%，      │
│ 主要受宏观环境影响，预计2024年反弹至15%  │
└─────────────────────────────────────────┘
```
左侧用主色竖线装饰，背景用主色极浅版（5%透明度）。

---

## 矩阵分析（2×2 Matrix）

**四象限标准布局**：
```
高 │ 象限II（高价值低难度）│ 象限I（高价值高难度） │
   │    Quick Wins        │   Strategic Bets      │
   ├──────────────────────┼───────────────────────┤
低 │ 象限III（低价值低难度）│ 象限IV（低价值高难度）│
   │    Fill-ins          │    Time Wasters       │
   └──────────────────────┴───────────────────────┘
        低                              高
                    实施难度
```

**气泡大小**：可用气泡大小表示第三个维度（如投资规模、影响人数）。

**常见矩阵类型**：
- 价值-难度矩阵（优先级排序）
- BCG矩阵（市场份额-增长率）
- 影响力-紧迫性矩阵（时间管理）
- 能力-意愿矩阵（人才管理）

---

## 漏斗分析（Funnel）

**梯形堆积结构**：
```
     ┌──────────────────────────┐
     │      认知 Awareness      │  100%
     └────────────────────────┘
          ┌──────────────────┐
          │   兴趣 Interest  │   65%
          └────────────────┘
               ┌──────────┐
               │ 考虑 Con │   38%
               └────────┘
                    ┌────┐
                    │购买│   12%
                    └────┘
```

**标注要素**：每层标注转化率（如 65% → 38%，转化损失27%），并用红色标注最大损失环节。

---

## 逻辑箭头（Arrow Logic）

**3-5步骤水平箭头流程**：
```
[步骤1]  →  [步骤2]  →  [步骤3]  →  [步骤4]
 图标         图标         图标         图标
 标题         标题         标题         标题
 描述         描述         描述         描述
```

**变体**：
- 循环箭头（表示持续优化循环）
- 垂直箭头（表示层级递进）
- 分叉箭头（表示决策分支）

**图标使用**：每个步骤配一个简洁的线条图标，图标风格必须统一（全用同一图标集）。

---

## 结论页（Conclusion）

**3点论结论框架**：
```
┌──────────────────────────────────────────────────────┐
│  核心结论                                             │
│  （1-2句话的Executive Summary）                       │
└──────────────────────────────────────────────────────┘

01 结论一          02 结论二          03 结论三
   支撑依据           支撑依据           支撑依据
   行动建议           行动建议           行动建议

┌──────────────────────────────────────────────────────┐
│  立即行动项（Next Steps）                             │
│  □ 行动1 - 负责人 - 截止日期                          │
│  □ 行动2 - 负责人 - 截止日期                          │
└──────────────────────────────────────────────────────┘
```
