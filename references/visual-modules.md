# 咨询专属可视化模块规范

本文档提供顶级咨询公司常用可视化模块的设计规范与实现参考。在 slides 工具的 `image` 模式下，这些模块通过精确的 HTML/CSS 描述来实现。

---

## 1. 编号徽章（Numbered Badge）

**用途**：步骤序列、优先级排序、章节编号

**设计规范**：
- 圆形或方形（圆角8px）
- 尺寸：48×48px（标准），64×64px（强调）
- 数字字体：Serif加粗，白色
- 背景：主色（深蓝/深红/炭黑）
- 变体：轮廓版（白底+主色边框+主色文字），用于次级信息

**在Prompt中描述**：
> 左侧竖排三个深海军蓝圆形徽章，内含白色Serif数字"01""02""03"，右侧对应三行标题和描述文字

## 2. 箭头逻辑图（Arrow Logic Diagram）

**用途**：流程步骤、因果关系、推进路径

**三种形态**：

### 水平推进箭头（最常用）
```
[框1] ──→ [框2] ──→ [框3] ──→ [框4]
 图标       图标       图标       图标
 标题       标题       标题       标题
 描述       描述       描述       描述
```
- 箭头：实心三角箭头，主色
- 框：圆角矩形，主色背景（深色）或白色背景+主色边框
- 步骤数：3-5步为佳，超过5步考虑分拆

### 循环箭头（持续改进）
```
      [步骤1]
   ↗           ↘
[步骤4]      [步骤2]
   ↖           ↙
      [步骤3]
```
- 用于PDCA、持续优化、闭环管理场景

### 收敛/发散箭头
```
[输入A] ──┐
[输入B] ──┼──→ [核心结论/输出]
[输入C] ──┘
```
- 用于多因素汇聚到一个结论

## 3. 矩阵象限图（2×2 Matrix）

**设计规范**：
- 四个象限等面积，用细线分隔（灰色 `#E5E7EB`）
- 轴标签：X轴底部居中，Y轴左侧垂直居中
- 象限标签：每个象限右上角，小号灰色文字
- 数据点：圆形气泡，颜色区分不同系列，气泡大小可表示第三维度
- 高亮象限：目标象限用极浅主色背景填充

**轴箭头**：X轴和Y轴末端用实心三角箭头，表示方向性

---

## 4. 漏斗图（Funnel Chart）

**设计规范**：
- 梯形堆积，从上到下逐渐收窄
- 每层高度相等（不按数值比例），宽度按数值比例缩减
- 颜色：同色系渐变（深→浅），或主色系各层不同深度
- 右侧标注：数值 + 百分比 + 转化率（如 "→ 转化率 38%"）
- 最大损失环节：用红色箭头或标注框突出显示

**在Prompt中描述**：
> 五层漏斗图，从上到下依次为"认知(100%)"、"兴趣(65%)"、"考虑(38%)"、"意向(22%)"、"购买(12%)"，使用深蓝到浅蓝的渐变色，右侧标注各层转化率，"考虑→意向"层用红色标注为最大流失环节

---

## 5. 瀑布图（Waterfall Chart）

**设计规范**：
- 起始柱和终止柱：深蓝色实心柱，标注总值
- 正向变动柱：绿色 `#059669`，从上一柱顶部开始
- 负向变动柱：红色 `#DC2626`，从上一柱顶部向下
- 连接线：灰色虚线，连接各柱顶/底
- 每柱顶部标注数值（+/-格式）

**典型场景**：
- 利润桥接：上期利润 → 收入增长 → 成本上升 → 本期利润
- 收入分解：基础收入 → 量增 → 价增 → 结构变化 → 总收入

---

## 6. 问题树可视化（Issue Tree Visualization）

**设计规范**：

**横向树状图（推荐）**：
```
                    ┌─── [子问题A1]
         ┌─[维度A]──┤
         │          └─── [子问题A2]
[核心问题]┤
         │          ┌─── [子问题B1]
         └─[维度B]──┤
                    └─── [子问题B2]
```

**颜色编码**：
- 根节点：主色满版背景，白色文字
- Level 1：主色系不同深度（如 `#002F6C`、`#1a5276`、`#2980b9`）
- Level 2：对应Level 1颜色的20%透明度版本，深色文字
- Level 3：白色背景，灰色边框

**连接线**：主色，1.5px，直角折线（L形）

## 7. 甘特图（Gantt Chart）

**设计规范**：

**表头**：周次（Week 1-12）或月份，灰色背景，小号文字

**行结构**：
- 阶段行：深色背景，白色文字，左侧缩进0
- 任务行：白色背景，灰色文字，左侧缩进16px

**色块**：
- 阶段1（诊断）：深蓝 `#1a3a5c`
- 阶段2（分析）：中蓝 `#2563eb`
- 阶段3（设计）：蓝绿 `#0891b2`
- 阶段4（实施）：绿色 `#059669`
- 里程碑：橙色菱形 ◆，大小12px

**里程碑标注**：菱形下方垂直文字或45度斜线标注交付物名称

## 8. 对比框（Comparison Box）

**双栏对比**：

```
┌────────────────────┬────────────────────┐
│  现状 / 问题        │  目标 / 解决方案    │
│  灰色标题栏         │  主色标题栏         │
├────────────────────┼────────────────────┤
│ ✗ 问题描述1        │ ✓ 改善方向1        │
│ ✗ 问题描述2        │ ✓ 改善方向2        │
│ ✗ 问题描述3        │ ✓ 改善方向3        │
└────────────────────┴────────────────────┘
```

**图标**：
- 现状/问题侧：红色 ✗ 或 ⚠ 图标
- 目标/解决方案侧：绿色 ✓ 或 → 图标
- 中间转化箭头：主色粗箭头 →，可加"转型"文字

---

## 9. 关键洞察标注框（Key Message Box）

**用途**：在数据图表旁标注最重要的结论，是咨询PPT的标志性元素

**设计规范**：
```
┃ Key Insight                              ┃
┃ 2024年Q4增速放缓至8%，主要受宏观环境影响，  ┃
┃ 预计2025年随政策刺激反弹至15%             ┃
```
- 左侧：主色竖线，4px宽
- 背景：主色5%透明度
- 标题"Key Insight"：主色，小号加粗
- 正文：深灰，正常字重，1-2句话

**位置**：通常放在图表右上角或右侧，不遮挡核心数据区域

---

## 10. 执行摘要框（Executive Summary Box）

**用途**：报告开头的核心发现总结，让高管快速获取关键信息

**设计规范**：
```
┌─────────────────────────────────────────────┐
│  Executive Summary                           │
├─────────────────────────────────────────────┤
│  01  [核心发现1，一句话结论]                  │
│      [1-2句支撑说明]                          │
│                                              │
│  02  [核心发现2，一句话结论]                  │
│      [1-2句支撑说明]                          │
│                                              │
│  03  [核心发现3，一句话结论]                  │
│      [1-2句支撑说明]                          │
└─────────────────────────────────────────────┘
```
- 标题栏：主色背景，白色文字
- 编号：主色圆形徽章
- 结论文字：深色加粗
- 说明文字：灰色正常字重

---

## 11. 价值主张卡片（Value Proposition Card）

**用途**：展示解决方案的核心价值，常用于Proposal中

**三列卡片布局**：
```
┌──────────┐  ┌──────────┐  ┌──────────┐
│  [图标]  │  │  [图标]  │  │  [图标]  │
│  价值1   │  │  价值2   │  │  价值3   │
│          │  │          │  │          │
│ 描述文字 │  │ 描述文字 │  │ 描述文字 │
│          │  │          │  │          │
│ 量化指标 │  │ 量化指标 │  │ 量化指标 │
└──────────┘  └──────────┘  └──────────┘
```
- 图标：线条风格，主色，48×48px
- 卡片：白色背景，轻微阴影（box-shadow: 0 2px 8px rgba(0,0,0,0.08)）
- 量化指标：大号数字，主色，加粗
