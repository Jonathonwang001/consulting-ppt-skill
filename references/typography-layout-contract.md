# 字体与版式工程契约

## 1. 规则分级

| 类别 | 要求 | 处理 |
|---|---|---|
| 工程硬门槛 | 完整文字可见、墨迹在约定文字内容区内、语义对象在画布内、无非预期裁切/遮挡、图表标签可读、字体正确 | 任一失败即暂停交付，修复并重渲染 |
| 项目设计契约 | 领导批准模板、项目字体/字号层级、边距、网格、图例、页脚等 | 按批准规范执行，修改有依据和明确记录 |
| 启发式 | 标题通常1–2行、列数、可视面积、密度、字数与字体风格 | 随真实内容、屏幕与阅读方式选择，不替代前两层 |

**取消每点15字、固定标题长度、60%面积或强制衬线等配额，不降低工程底线。** 不能以“内容关系驱动”批准漏字、溢框、挡住坐标轴或字体替代。

## 2. 先建立排版契约

优先复用领导认可的字体、版式和母版；不要凭审美重新发明网格。记录画布宽高、四边安全区、标题/副标题/正文/标签/来源/页脚字体与字号、粗细、行距/段距、文字框内边距、图表标签安全区、导出与目标阅读环境。

没有样板时，建立一套可读的中文字体+拉丁/数字字体，正文不混多套家族。中文字符、负号、百分号、特殊符号、单位、粗体与上下标都须验证。投屏版16:9可先以标题28–36pt、正文18–24pt、标签14–18pt试排；它们是起始值，须按屏幕/视距校准。会前阅读可使用更细的表格层级，但需以实际显示或打印可读性复核，不把小于某数值自动判为合理或合格。

来源与必要口径不能因小字不可读而消失。版内使用角色一致的字号与层级；不逐框随意缩小，不能把AutoFit最小字作为默认补救。衬线可在已有模板中合法使用，最终中文覆盖和字形正确是必需。

## 3. 文字完整与零溢出

逐对象检查：

1. **外框与画布**：文字/图表/图片等语义元素的变换后边界在画布内；允许背景/出血装饰例外必须明确且不含关键文字，不能用于掩盖溢出。
2. **内容框**：从文字框扣除内边距，形成允许的文字内容区。完整字形墨迹、项目符号、上/下标、注释和换行均在该区；检查左右上下四边，而非只看框是否在页内。
3. **完整性**：渲染文本和内容稿逐项核对，长句尾部、最后一行、长英文/URL、单元格、多层项目符号尤其检查。文字被裁到框内仍可能漏字，bbox通过不能证明完整。
4. **字体替代**：实际打开/导出时缺失字体、字符方框、替换字形或换行漂移必须处理；“可编辑”文件也要复核目标应用。
5. **无遮挡**：无文字互压、线穿标签、图标遮数值、框挡脚注；有意层叠的底板/图片/引线不能挡住语义内容。

字数估算、PPT XML中框尺寸、AutoFit开关仅用于预防或线索，**不构成实际字形无溢出的证明**。

## 4. 图表与表格

图例/数据标签可在绘图区外，但必须处于声明的标签安全区和页面内；不将plot rectangle直接当作全部图表的文字边界。轴标题、刻度、负号、单位、图例、误差线、显著性与来源均完整。组合图的坐标尺度、期间、分母、单位和对齐解释清楚。

表格单元格的墨迹不越界、表头和数字右对齐规则一致、比较列按同口径排；跨页拆表须重复表头并保持阅读顺序，避免一行撕裂或脚注归属不明。边框、图例、标签不得为装饰挤占必要证据。

## 5. 修复顺序与回归

先核对原始内容与本页读者任务→去除重复/无支撑句、保留有效事实和风险→调整换行、内边距、列宽与模块分配→合并冗余结构或拆出配套证据页/同稿支撑→仅在项目字号契约内微调字体→重渲染原页、相邻页和同模板页面。

不删必要反证/假设以腾空间，不把信息剪裁到不可见处，不用无限缩字解决。重要图表+机制可以协调成两个证据面板，参见`composite-visual-evidence.md`，避免物理覆盖。

## 6. 实际文件验收

先内容稿检查，再创建，再最终格式渲染；每页先适屏看层次，再放大检查边界/尾行/坐标标签。全部页面均审阅，高风险页额外细看；校验后任何改字、换字体、挪图或改变导出方式都可能失效，相关页面重验。

提交记录包含文件/版本或哈希、渲染工具/版本、目标字体/替代情况、页/对象ID、检查结果、未决项、修复与复验；没有真实渲染不得填“无溢出已通过”。可编辑文件与预览/PDF渲染不同，需要按实际交付格式核对；用户只要PPT时不强造冗余PDF作为第二主稿。

`check_layout_metrics.py`仅检查输入的实测几何与审阅声明，其字段契约见`layout-metrics-contract.md`。真实指标来源和完整性仍需负责人员核实；合成例子只能测试算法，不能用于真实PPT验收。手工审阅有页/对象证据也可验收，不能因工具不支持bbox就用假测量过检。
