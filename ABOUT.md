# About / 关于本项目

## 中文

**Consulting PPT Skill** 由[@Jonathonwang001](https://github.com/Jonathonwang001)维护，帮助AI设计Proposal、内外成果/研究汇报、领导/投委会材料、战略研讨与工作交流。v2.1.1统筹受众、用途、证据成熟度、媒介与交付约束：先建立整稿故事线、章节信息预算和一致口径，再采用适合的页面/图表/结构/图标。

商业性冷淡风以精准表达、有效深度、商务美观和工程严谨为底线。保留Proposal方法但不强套所有材料；结构与数据证据可协调叠加，零溢出/裁切/遮挡和字体完整为硬门槛。合理消除无意义留白，不靠删风险或缩字堆满页面。

获批且适配当前任务的参考优先；麦肯锡深蓝、罗兰贝格酒红、德勤炭灰/蓝灰且绿只点缀、BCG深绿为非官方启发预设。报告优先Markdown，演示优先可编辑PPTX；按需配Mermaid、CSV与实际所用Python源文件，直观成品为入口。A4打印/报告与投屏分别验收。

宿主工具实际制作和渲染，规划/bbox脚本不代替事实、编辑能力或全页审阅。本仓库只维护Skill，不包含在线产品、原图标全集或真实稿自动认证承诺。原创规则/示例/脚本MIT许可，源教材/图标/商标和私密内容不公开或重新授权。

## English

**Consulting PPT Skill**, maintained by [@Jonathonwang001](https://github.com/Jonathonwang001), supports proposals, internal/external research and results, executive/committee materials and working discussions. Version 2.1.1 coordinates audience, purpose, evidence maturity, medium and delivery constraints. Whole-document narrative, chapter information budgets and consistent evidence precede page-level styling.

Preserve effective depth and risks, coordinate visual evidence, and enforce complete text/font and zero-overflow gates. Non-proposal materials do not inherit sales closure. Prefer appropriate approved references, editable Markdown/PPTX and optional Mermaid/CSV/actually used Python sources behind a clear human-facing artifact. Validate A4 reports/print separately from projection; reduce purposeless whitespace without overcrowding.

Host tools author/render actual files. Planning/declared-bounds scripts cannot certify facts, editability or actual decks. The repository contains original skill rules/examples/scripts under MIT, not a web product, proprietary source artwork or confidential client content.
